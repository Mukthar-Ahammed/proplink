# External services and credentials registry

This registry tracks configuration requirements, not credential values. Never
paste secrets into this file, source control, chat or issue comments. Local
secrets belong in ignored `.env.local`; deployment secrets belong in the
environment's secret manager. Use separate credentials for development,
staging and production and record verification/rotation metadata in the
appropriate private operations system.

| Service                    | Purpose                                          | Configuration keys                                                                                                                                                      | Current state                                                                                                                    | Boundary and notes                                                                                                                                                     |
| -------------------------- | ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Supabase Auth / PostgreSQL | Authentication, identity bridge, business data   | `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, `DATABASE_URL`, `DIRECT_URL`; `SUPABASE_SERVICE_ROLE_KEY` for isolated staging-fixture scripts only | Supabase Auth is the active auth provider. No Phase 0 database inspection or migration was performed.                            | Publishable key and URL are public. Database URLs and service-role key are server-only. Never import service-role adapters from application modules or client bundles. |
| Upstash Redis              | Distributed rate limiting and cache              | `RATE_LIMIT_PROVIDER`, `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`                                                                                             | In-memory adapter is local-development only; production requires Upstash and fails closed if unavailable.                        | REST token is server-only.                                                                                                                                             |
| Cloudflare Turnstile       | Bot protection                                   | `TURNSTILE_PROVIDER`, `TURNSTILE_ENABLED`, `TURNSTILE_SECRET_KEY`, `NEXT_PUBLIC_TURNSTILE_SITE_KEY`                                                                     | Local mock is supported. Production requires Cloudflare verification.                                                            | Secret key is server-only; site key is public.                                                                                                                         |
| Resend                     | Transactional email                              | `EMAIL_PROVIDER`, `EMAIL_FROM`, `RESEND_API_KEY`                                                                                                                        | Local mock is supported; real delivery is not verified for this phase.                                                           | API key is server-only.                                                                                                                                                |
| Sentry                     | Error reporting                                  | `SENTRY_DSN`, `NEXT_PUBLIC_SENTRY_DSN`                                                                                                                                  | Optional until configured; event scrubbing removes user identifiers and request payloads.                                        | DSNs are deployment configuration; do not attach unsanitized event data.                                                                                               |
| AWS S3 / malware scanner   | Upload quarantine, scanning and private storage  | `STORAGE_PROVIDER`, `UPLOADS_ENABLED`, S3 bucket settings, `MALWARE_SCANNER_PROVIDER`, `MALWARE_SCANNER_URL`, `MALWARE_SCANNER_TOKEN`                                   | Production uploads must remain disabled until quarantine, scanning, private promotion and access-checked downloads are complete. | AWS/scanner credentials are server-only. Public mock uploads are local-only.                                                                                           |
| Google Maps                | Geocoding, maps and routes                       | `GOOGLE_MAPS_SERVER_KEY`, `GOOGLE_MAPS_API_KEY`                                                                                                                         | Mock implementations are available; real provider is not verified.                                                               | Server key is private; browser key must be restricted by origin and API. Cache before provider calls.                                                                  |
| Stripe                     | Agent subscriptions, boosts and advertising only | `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`                                                                                                                            | Not enabled for investment funds. Webhook integration is not a Phase 0 release gate.                                             | Never create charges for pledges; webhook verification/idempotency required before enabling.                                                                           |
| Anthropic                  | Future intelligence features                     | `ANTHROPIC_API_KEY`                                                                                                                                                     | Deferred; no Phase 0 feature calls this provider.                                                                                | Server-only; Redis cache required before calls.                                                                                                                        |
| Sumsub / e-sign / Pusher   | Future KYC, agreements and realtime workflows    | Provider-specific keys and webhook secrets                                                                                                                              | Not configured for this phase.                                                                                                   | Implement behind server-only interfaces with local mocks and signed, idempotent webhooks.                                                                              |
| Gitleaks                   | Secret scanning                                  | No application secret                                                                                                                                                   | CI action added; local executable is unavailable, so the scan has not been run here.                                             | Install locally before committing; the pre-commit hook fails closed when absent.                                                                                       |

Credential setup guides are in [`credentials/`](./credentials/). A service is
not production-ready just because its environment variables exist: require
least-privilege access, a smoke test, rotation metadata, and a documented
fallback before enabling it.
