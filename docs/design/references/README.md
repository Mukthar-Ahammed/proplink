# Design reference images

Put reference screenshots from other websites in this folder. The redesign spec
(`docs/design/WEBSITE-DESIGN-SPEC.md`) is built from them.

## How to add them

1. Put the images in the sub-folder that matches what they show (create any that are missing):

   | Folder        | What goes in it                                                  |
   | ------------- | ---------------------------------------------------------------- |
   | `overall/`    | Whole-page screenshots showing the general look and feel        |
   | `navbar/`     | Headers and navigation, desktop and mobile menus                 |
   | `footer/`     | Footers                                                          |
   | `home/`       | Landing-page sections (hero, features, stats, testimonials, CTA) |
   | `auth/`       | Login, sign-up and password-reset pages                          |
   | `search/`     | Property search, results lists, filters, maps                    |
   | `property/`   | Property detail pages, galleries                                 |
   | `dashboard/`  | Logged-in dashboards, sidebars, tables, cards                    |
   | `components/` | Single elements you like: buttons, forms, cards, badges, modals  |
   | `colors-type/`| Colour palettes and font pairings you like                       |

2. Name each file `<site>-<what>.png` so it can be identified later, for example
   `rightmove-search-filters.png` or `stripe-home-hero.png`.
3. Optional: add a note below saying **what you like** about each image (the
   colours, the layout, the font, how the menu opens…). One line is enough.

Supported formats: PNG, JPG, WEBP. Full-page screenshots are best for layout.
